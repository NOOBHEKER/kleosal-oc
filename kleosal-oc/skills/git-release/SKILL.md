## What I do

- Draft release notes from merged PRs
- Propose a version bump (semver: major / minor / patch)
- Provide a copy-pasteable `gh release create` command
- Summarize notable changes by category (features, fixes, chores)

## When to use me

Use this when preparing a tagged release. Ask clarifying questions if the target
versioning scheme is unclear (e.g., CalVer vs SemVer, monorepo tags).

## Rules

- Group changes logically, not chronologically
- Mark breaking changes explicitly
- Keep notes scannable — bullet points over prose
- If no PRs found, say so instead of inventing changes
